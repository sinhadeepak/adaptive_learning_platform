# mobile

Flutter app for iOS + Android (per [ADR-0002](../../docs/adr/0002-flutter-mobile-stack.md)).

> **Sprint 0 scope**: stub `main.dart`. On first workstation setup, run `flutter create .` inside this folder to generate the platform folders (`ios/`, `android/`, `macos/`, etc.) that are not checked in at this stage.

## Run locally

```bash
flutter pub get
flutter run       # requires simulator/device
flutter test
flutter analyze
```
